# Aman Patel — Portfolio

Personal portfolio website for Aman Patel, Product & UX Designer based in Ahmedabad, India.

## Stack

Static site — HTML + CSS + React (via CDN) + JSX transpiled by Babel standalone. No build step needed.

## Files

- `index.html` — entry point
- `styles.css` — all styles
- `icons.jsx` — SVG icon components
- `sections.jsx` — all page sections as React components
- `app.jsx` — root app + render
